# Moog's Fortress Reimagined

A reimagined nether fortress for Minecraft: a huge, many-roomed fortress that comes intact, damaged or ruined. The more ruin, the tougher the fight and the better the loot. It replaces the vanilla nether fortress by default.

This mod is a datapack-style structure mod built on [Moog's Structure Lib](https://www.curseforge.com/minecraft/mc-mods/moogs-structure-lib).

**Work in progress.** There is no release yet and no CurseForge or Modrinth page.

This branch (`1.20-datapack`) targets Minecraft 1.20 to 1.20.6.
